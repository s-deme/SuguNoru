# 江東・墨田エリアの路線候補

## 現在の乗車・降車選択

以下の調査一覧は路線候補の出典。同梱カタログは路線IDと表示名だけを保持し、
ODPTのBusroutePatternとBusstopPoleから経路別の全停留所・通過順・名称を取得する。
乗車後に到達できる別の停留所を降車候補に出し、取得した経路は端末に保存する。
通信がない場合は保存済み経路を使用し、未取得の場合は通信とODPTトークンが必要。
停留所選択画面の「停留所を更新」で再取得できる。取得失敗時は選択もキャッシュも上書きしない。

時刻表は各便の通過順を確認し、乗車可能な停留所より後に降車可能な停留所がある便だけを使う。
終点名との文字列一致では判定しない。降車指定はバックアップ・復元・自動更新でも保持する。
旧登録は従来どおり方面指定として読み込み、新しい降車指定とは区別する。

仕様の根拠：[ODPT公式API仕様](https://developer.odpt.org/documents)。
経路・時刻表の順序はodpt:index、名称はBusstopPoleのdc:title、乗降可否はドア情報と
BusTimetableのcanGetOn/canGetOffを使用。任意の注記を停留所名と解釈しない。
実APIへの認証付き通信は、この開発環境では未検証。

検証：JDK 17以上とAndroid SDKを設定し、
`./gradlew.bat -I scripts/verification.gradle testDebugUnitTest connectedDebugAndroidTest lintDebug`。
エミュレーターへのインストールは別パッケージ `jp.sugunoru.app.verification` を使う。
JSON・バックアップ・画面テストの経路データは人工の検証用データであり、実運行データではない。

## 運行上の区別

- 亀戸駅前・亀戸駅通り・水神森は別停留所。都07は亀戸駅通りから乗車する。
- 門前仲町二丁目と門前仲町も別停留所。門33の二丁目停留所は豊海水産埠頭方面。
- 錦18は平日、急行05・急行06は土休日の運行。両28の一部行き先や陽12-2の豊洲市場行きは時間帯による。
- 候補は系統単位の停留所・行き先一覧なので、各停留所から全行き先に乗れることを保証しない。取得した公式時刻表で運行日・乗車方向を確認する。
- [木11甲の運行情報](https://tobus.jp/blsys/navi?ECD=NEXT&LCD=&RTMCD=45&VCD=cslrsi)で新木場循環・若洲キャンプ場前・東陽町駅前・木場駅前を確認。
- [陽12-1の運行情報](https://tobus.jp/blsys/navi?ECD=NEXT&LCD=&RTMCD=190&VCD=cslrsi)に合わせ、病院停留所名は「昭和大学江東豊洲病院前」とした。
- [直行03の運行情報](https://tobus.jp/blsys/navi?ECD=NEXT&LCD=&RTMCD=188&VCD=cslrsi)は日本科学未来館への片方向。帰り方向を生成せず、対象駅側の乗車停留所だけを収録した。

ODPT連携の実データ取得はアクセストークンが必要であり、この更新のオフライン検証には含まない。
