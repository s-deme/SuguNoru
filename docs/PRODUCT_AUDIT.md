# 製品化レビューと実装結果

レビューで採用した改善は、以下の全項目を実装済みです。外部事業者との契約や対象地域の決定が必要なものは、この一覧へ混ぜていません。

## 製品機能

1. **比較結果の自動更新** — 分が変わると候補と待ち時間を再計算する。
2. **日時シミュレーション** — 任意の日付・時刻で、行き／帰りの候補を事前確認できる。
3. **翌日便探索** — 終電・終バス後も翌営業日の便を探す。
4. **祝日ダイヤ** — 路線ごとの祝日時刻表と、利用者が指定する祝日・臨時休日に対応する。
5. **最終徒歩を含む比較** — 降車後の徒歩を到着見込みへ加える。
6. **候補の一時無効化** — 季節運行などを削除せず比較対象から外せる。
7. **時刻表の有効期限** — 期限30日前から警告し、期限切れを明示する。
8. **乗り場メモ** — ホーム、出口、バス停位置などを候補カードに表示する。
9. **登録の複製** — 往路・復路や似た系統を少ない入力で作れる。
10. **等間隔ダイヤ生成** — 始発、最終、間隔から時刻群を作成できる。
11. **サンプル導入** — 空状態から動作を試し、そのまま編集できる。
12. **出発通知** — 次便に間に合う出発時刻にローカル通知する。
13. **通知の一括取消・OS設定導線** — 誤設定から復旧できる。
14. **ホーム画面ウィジェット** — アプリを開かず最速候補、次発、到着見込みを確認・更新できる。
15. **JSON書き出し** — 機種変更や編集前のバックアップを作成できる。
16. **JSON読み込み** — 追加または全置換を選び、安全に復元できる。
17. **自動世代バックアップ** — 保存前の状態を1世代保持し、設定から戻せる。
18. **壊れた保存データからの復旧** — 現行データが読めない場合、自動バックアップを利用する。
19. **行き／帰り選択の保持** — 再起動・ウィジェットでも最後の選択を利用する。

## UI・UX・アクセシビリティ

20. **3ダイヤ切替** — 平日／土日／祝日を明確に切り替える。
21. **インライン入力エラー** — 必須項目と時刻形式の誤りを入力欄で示す。
22. **入力形式の寛容化** — `07:35`、`0735`、全角コロン、空白、改行、カンマ、読点を受け付ける。
23. **最速理由の可視化** — 乗るまで、乗車、降車後、到着見込みを同じカードに表示する。
24. **試算状態の明示** — 現在時刻と将来日時を混同しない表示と復帰導線を付ける。
25. **無効候補の管理導線** — ホームから消えても設定画面で確認・再編集できる。
26. **48dp以上の主要操作領域** — タップしやすさを改善する。
27. **読み上げ情報** — 候補カードに路線、時刻、待ち時間、操作内容をまとめた説明を設定する。
28. **ラベルと入力欄の関連付け** — 支援技術で入力目的が分かるようにする。
29. **画面回転時の状態保持** — 開いていた画面、選択路線、試算日時、フォーム入力を復元する。
30. **大画面対応** — タブレット・横画面では読みやすい最大幅に制限し中央配置する。
31. **エッジツーエッジ対応** — システムバーのInsetsを適用し、Android 15以降で重なりを防ぐ。
32. **画面回転制限の撤廃** — 折りたたみ端末・ChromeOS・マルチウィンドウに対応する。
33. **データ処理中の安全策** — インポートは2MBに制限し、不正データでは既存登録を変更しない。
34. **プライバシーの明示** — 通信、位置情報、アカウント、分析SDKを使わないことをアプリ内に表示する。

## 開発体験・品質

35. **後方互換な保存スキーマ** — 旧データへ既定値を補い、追加項目後も読み込める。
36. **保存のトランザクション化** — 保存成功後にだけ画面上の状態を更新する。
37. **時刻計算の単体テスト拡充** — 秒の切り上げ、徒歩、翌日、祝日、無効化、最終徒歩、到着順を検証する。
38. **再現可能なGradle Wrapper** — 開発端末へGradle本体を要求しない。
39. **ワンコマンド検証** — `scripts/check.ps1` で clean、test、lint、APK生成を実行する。
40. **継続的インテグレーション** — GitHub Actionsで同じ検証を行いAPKを成果物として保持する。
41. **製品仕様・制約の文書化** — 判定式、データ範囲、受け入れ条件、外部データ連携条件を明文化する。
42. **ネットワーク権限なし** — 不要な攻撃面とプライバシーリスクを増やさない。
43. **ランチャーショートカット** — アイコン長押しから「出かける」「帰る」を直接開く。
44. **アダプティブ・モノクロアイコン** — 端末の形状・テーマアイコンへ自然に適応する。

## 外部連携の境界

自動時刻表取得、リアルタイム遅延、乗換検索は、対象事業者、利用規約、API鍵、GTFS配布条件を決めて初めて実装仕様が確定する機能です。現時点で架空のスクレイピングや特定事業者依存コードは製品品質を下げるため入れていません。バックアップ形式はバージョン付きJSONとしており、将来のGTFSインポーターや正規APIコネクターを追加できる境界を確保しています。
