# すぐのる

「出かける」「帰る」それぞれで、よく使う都営バスの次の便をすぐ確認する個人向け Android アプリです。現在の製品版は `2.1.1` です。

## できること

- 出かける／帰るをタブで切り替え、それぞれに路線を登録
- 都営バスの路線・系統、乗車停留所、降車停留所を順に選択
- 入力なしで現在時刻からの次の便を発車時刻順に表示
- 次の3便と、平日／土日の駅・停留所時刻表を表示
- 交通事業者の公式時刻表ページ（HTTPS）から平日／土日／祝日の時刻を取得
- ODPT APIから選択した都営バス停・方面の時刻表を取得
- 取得済みの時刻表を端末に保存し、オフライン時は最終取得データを使用
- 祝日・臨時休日ダイヤ、出発通知、ホーム画面ウィジェット
- JSONバックアップ／復元、1世代の自動バックアップ
- 時刻表用の等間隔ダイヤ生成
- 登録内容を端末内に保存し、通信なしで利用
- `07:35`、`0735`、全角コロン、空白・改行・カンマ区切りの時刻入力に対応

## 使い始める

1. ホームで「路線を追加」を押し、「出かける」または「帰る」の路線を登録します。
2. 路線・系統、乗車停留所、降車停留所を選び、時刻表を設定します。停留所の初回取得には設定画面のODPTアクセストークンと通信が必要です。
3. ODPTを使う場合は「設定とバックアップ」→「ODPT API」でアクセストークンを保存し、登録画面の「ODPTから時刻表を取得」を押します。公式ページから取得する場合はURLを設定します。
4. 通知、ウィジェット、JSONバックアップは「設定とバックアップ」から設定できます。

## 利用上の注意

交通事業者ごとに公開形式や利用規約が異なるため、公式時刻表は登録したHTTPSページから取得します。一般的なHTMLの時刻表（`07:35`形式、または時間と分が分かれた表）と簡易JSONを読み取ります。ログインが必要なページやJavaScriptだけで表示されるページは対象外です。運休・遅延、位置情報、乗換案内は対象外です。

登録画面には都営バス57系統の路線候補を同梱しています。乗車・降車停留所はODPTから取得した経路別の全停留所から選び、手入力はしません。乗車後に到達できる停留所だけを降車候補に出し、ODPT時刻表はその区間を実際に走る便から取得します。往復・分岐・循環を別経路として扱い、途中止まりや乗降できない便を除外します。

取得した停留所データは端末に保存し、オフラインでも再選択できます。更新は乗車停留所の選択画面にある「停留所を更新」から行います。ODPTに経路や停留所名がない系統は選択を完了できません。旧版の方面指定の登録はそのまま使え、路線から選び直すと降車指定に切り替わります。区間を変えると以前の時刻表を消し、別区間の便の流用を防ぎます。[調査元と収録範囲](docs/TRANSIT_CATALOG.md)を参照してください。

ホームでは、現在時刻以降で最も早い登録便を各路線から取り出し、発車時刻が早い順に並べます。乗換・遅延は含みません。

## データとプライバシー

登録内容と最終取得した時刻表は Android のアプリ専用 `SharedPreferences` に JSON として保存されます。ODPTアクセストークンはこの端末だけに保存し、JSONバックアップ、ソースコード、APKには含めません。ODPTまたは公式ページを設定した路線は、前回取得から24時間以上経過している場合にアプリ起動時に更新します。このとき送るのは時刻表の取得リクエストだけで、他の登録内容は送信しません。更新できない場合は時刻表を上書きせず、保存済みの最終取得データを使います。OSクラウドバックアップは無効です。必要なときは設定画面からJSONを書き出してください。アプリをアンインストールすると端末内データは削除されます。
